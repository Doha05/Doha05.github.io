🐥 도하 스튜디오 🏠 메인으로 돌아가기

🌐 깃허브 + 개인 도메인(.kro.kr) 완벽 연결 가이드

도하 스튜디오에서 제작한 홈페이지를 고객님만의 주소로 연결하고 안전한 HTTPS(자물쇠 마크)를 적용하는 방법입니다. 천천히 따라 해보세요!

1단계: 깃허브(GitHub)에 호스팅용 저장소 만들기

1. GitHub에 로그인한 뒤, 우측 상단의 [New] 버튼을 눌러 새로운 저장소(Repository)를 만듭니다.
2. Repository name(저장소 이름) 칸에 반드시 본인깃허브아이디.github.io 라고 정확히 적어주세요. (예시: 내 아이디가 doha라면 doha.github.io)
3. 아래 설정에서 [Public] (전체 공개)이 체크되어 있는지 꼭 확인하세요! Private(비공개)으로 설정하면 웹사이트가 열리지 않습니다.
4. [Create repository] 버튼을 눌러 생성한 뒤, 도하 스튜디오에서 받은 HTML 파일들을 업로드합니다.

2단계: '내 도메인 한국'에서 무료 도메인 발급받기

1. '내 도메인 한국' 사이트에 접속해 로그인합니다.
2. 원하시는 주소(예: doha-studio.kro.kr)를 검색하여 내 소유로 등록합니다.
3. 등록을 마친 후, 도메인 관리 탭에서 [고급 설정(DNS)] 버튼을 클릭해 설정 창을 엽니다.

3단계: 별칭(CNAME)으로 깃허브 주소 연결하기

IP 주소를 여러 개 입력할 필요 없이, 가장 쉽고 확실한 CNAME 방식을 사용합니다.

1. '내 도메인 한국'의 고급 설정(DNS) 창에서 [별칭(CNAME)] 추가 항목을 찾습니다.
2. 목적지(값) 입력 칸에 1단계에서 만든 본인의 깃허브 호스팅 주소인 본인아이디.github.io 를 적어주고 저장을 누릅니다.

4단계: 깃허브 페이지에 도메인 등록하기

1. 다시 깃허브의 본인아이디.github.io 저장소 화면으로 돌아옵니다.
2. 상단 메뉴의 [Settings(설정)] ➡️ 왼쪽 메뉴의 [Pages] 탭을 클릭합니다.
3. 화면 중간쯤에 있는 [Custom domain] 칸에 방금 발급받은 도메인(예: doha-studio.kro.kr)을 입력하고 [Save]를 누릅니다.

5단계: 보안 연결(HTTPS) 적용하기

1. 4단계에서 도메인을 저장하고 나서, 깃허브가 전 세계 서버에 주소를 알리는 시간(약 10분~15분)을 기다려주세요.
2. 시간이 지난 후 페이지를 새로고침 해봅니다.
3. Custom domain 칸 바로 아래에 있는 [Enforce HTTPS] 체크박스가 활성화되면 클릭해서 체크해 줍니다.
4. 축하합니다! 🎉 이제 주소창에 안전한 자물쇠 마크가 뜨는 완벽한 나만의 홈페이지가 완성되었습니다.
