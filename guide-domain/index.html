🐥 도하 스튜디오 🏠 메인으로 돌아가기

🌐 내 도메인(.kro.kr)과 깃허브 연결하기

도하 스튜디오에서 제작한 홈페이지를 고객님만의 주소로 연결하고 안전한 HTTPS를 적용하는 방법입니다.

1단계: 내 도메인 한국에서 무료 도메인 발급받기

1. '내 도메인 한국' 사이트에 접속해 로그인합니다.
2. 원하시는 주소(예: `doha-studio.kro.kr`)를 검색하여 등록합니다.
3. 도메인 관리 탭에서 [고급 설정(DNS)]으로 들어갑니다.

2단계: 깃허브 서버 IP 주소 입력하기 (A 레코드)

'내 도메인 한국'의 고급 설정 창에서 IP(A) 항목에 아래 깃허브의 고정 IP 주소 4개를 모두 추가해 줍니다.

185.199.108.153
185.199.109.153
185.199.110.153
185.199.111.153

3단계: 깃허브 페이지에 도메인 등록하기

1. 고객님의 GitHub 리포지토리로 이동합니다.
2. 상단의 [Settings] -> 왼쪽의 [Pages] 탭을 클릭합니다.
3. 화면을 살짝 내려서 [Custom domain] 칸에 방금 발급받은 도메인(`doha-studio.kro.kr`)을 입력하고 [Save]를 누릅니다.

4단계: 보안 연결(HTTPS) 적용하기

1. 도메인을 저장하고 나서 약 10분~15분 정도 깃허브가 DNS를 확인하는 시간을 기다립니다.
2. 페이지를 새로고침 한 뒤, Custom domain 바로 아래에 있는 [Enforce HTTPS] 체크박스를 체크합니다.
3. 축하합니다! 이제 안전한 자물쇠 마크가 뜨는 나만의 홈페이지가 완성되었습니다 🎉
